# AV5marial
Sequência para baixar meu programa do repositório e depois executá-lo:

            BAIXAR  
I. Entre no terminal e digite: git clone https://github.com/xximmary/AV5marial
    |--> desse jeito, todos os arquivos necessários serão baixados automá-
    ticamente para sua máquina =)

            EXECUTAR
I. Ainda no terminal, digite: cd AV5marial
    |--> esse comando entrará na pasta criada do repositório
II. Agora, digite: uv run bandas.py
    |--> o comando "uv run" irá rodar o programa no próprio terminal
